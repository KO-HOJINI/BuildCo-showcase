# Build&Co

**인력사무소 일용직에서 시작해, 친구들과 시공사를 세우고 키워 가는 협동 건설 라이프 & 타이쿤**

Steam 출시를 목표로 개발 중입니다. (스토어 페이지 준비 중)

---

## 어떤 게임인가
한국 건설 현장을 배경으로, 현장의 가장 아래에서 시작해 회사를 키우는 게임입니다. 장비 하나를 잡고 의뢰를 수행하는 기존 건설 시뮬레이터와 달리, **인생 역전 커리어**와 **함께 꾸리는 회사**가 중심입니다.

- **손으로 하는 일:** 철근 결속, 보통인부 작업처럼 직종마다 직접 해야 하는 작업이 있습니다. 숙련도가 오르면 더 좋은 일자리가 열립니다.
- **피로와 안전:** 무리하면 사고가 나고, 보호구를 챙기면 안전합니다. 사고는 위험한 행동을 한 결과로만 일어나도록 설계해 억울하지 않게 합니다.
- **협동:** 신호수 없이는 장비를 쓸 수 없는 식으로, 역할을 나눠 맡는 협동 플레이가 기본 설계입니다.
- **분위기:** 현실 고증 7~8, 코미디 2~3의 비율을 지향합니다.

## 성장 경로
일용직으로 시작해 한 단계씩 올라갑니다. 어떤 단계에서 멈춰도 같은 가치로 보상받는 게 목표라, 정해진 엔드게임은 없습니다.

```
일용직 → 전문 기능공 → 반장·소장 → 소규모 시공사 창업
      → 중견 시공사 → 대형 프로젝트 수주 → (선택) 해외 현장 진출
```

| 단계 | 하는 일 |
|---|---|
| 일용직 | 구인 게시판에서 일자리를 골라 현장에 투입, 직접 작업하고 일당을 받음 |
| 기능공 / 장비 기사 | 자격을 따고 숙련도를 쌓아 더 높은 일당의 일을 맡음 |
| 팀장 · 소규모 시공사 | 공종 하나를 위탁받아 인력과 장비를 운영 |
| 종합 시공사 | 수주, 하도급 선정, 현장소장 배치, 회사 조직 운영 |
| 해외 진출 (장기 비전) | 동남아·중동 등 해외 현장. 현지 파트너와 환율·공기 리스크를 다루는 선택형 목표 |

- 실패는 목적이 아니라 운영 리스크입니다. 어려워질 수는 있어도 복구할 길이 항상 있습니다. 해외 사업이 틀어져도 국내 사업으로 돌아올 수 있습니다.
- 소규모 장인 회사, 특화 시공사처럼 키우는 방식이 달라도 같은 가치로 인정합니다.

## 내가 지은 것이 남는 월드
- 도시와 지역은 하나의 월드로 이어지고, 플레이어가 지은 건물·도로·교량은 **영구히 남습니다.**
- 멀리서도 이전에 일했던 현장과 지형지물이 보이는, 마을 이상 규모의 지역을 목표로 합니다.
- 신도시 외곽에서 시작해 농촌, 산업단지, 산악·고속도로 구간으로 단계적으로 열리고, 지역마다 단가와 발주 성향이 다릅니다.
- 건축에서 시작해 도로, 교량, 터널 순으로 공종을 넓힙니다.

## 현재 상태
알파 개발 중입니다. 지금은 아래 흐름이 동작합니다.

- 메인 메뉴, 허브, 구인 게시판, 출근 준비(보호구 착용), 하루 시계
- **구인 게시판:** 현장 여러 곳이 각자 공정을 가지고, 직종·일당·요구 숙련도가 다른 공고가 올라옵니다. 숙련도가 모자라면 공고가 잠깁니다.
- **직무:** 보통인부(자재 정리·쌓기·청소), 철근 결속, 가설공(울타리 설치)이 동작합니다. 형틀과 콘크리트공은 구현·검토 중입니다.
- **현장 공정:** 가설 정리 → 가설 울타리 → 배근 → 거푸집 → 타설 → 준공 검사의 순서로 현장 하나가 완성됩니다. 하루에 한두 공정을 처리하고, 못 끝낸 공정은 다음 날 같은 현장 공고로 다시 나옵니다.
- 피로 게이지, 점심 선택, 위험 행동 경고와 사고
- 하루 끝 정산(일당, 직무 경험치, 품질, 안전)과 자동 저장
- 직접 만들거나 무료 라이선스(CC0)로 가공한 3D 소품과 임시 캐릭터

## 다음 단계: 더 현실적인 공정 (알파 1a-3)
지금의 직무는 "자재 하나를 놓고 판정"하는 수준입니다. 알파 1a-3에서는 직무마다 실제 공사 순서대로 한 단계씩 직접 손으로 하도록 바꿉니다.

- **가설공:** 줄을 긋고, 삽으로 바닥을 파고, 파이프를 세워 망치로 박은 뒤, 가로 파이프와 대각 버팀대를 걸고 클램프로 고정하고 패널을 겁니다.
- **철근:** 불량 철근을 눈으로 골라내고(녹은 브러시로 벗겨 무게를 확인), 한 개씩 운반해 간격에 맞춰 놓은 뒤 결속합니다.
- **형틀·콘크리트공:** 줄긋기, 합판 세우기, 수평 맞춰 동바리 받치기, 못 박기 / 채우기, 다짐, 마감.
- **원칙:** 선행 단계만 강제하고 앞 단계의 오차가 뒤 단계 품질에 이어집니다. 잘못 한 일은 버튼이 아니라 직접 되돌립니다(구덩이를 다시 메우고, 박은 파이프를 뽑음). 한 공정은 약 8~12분 안에 끝나도록 맞춥니다.
- **협동 대비:** 한 사람이 파이프를 잡고 다른 사람이 클램프를 조이는 식의 두 사람 동작을 구조에 넣어 두고, 싱글에서는 동료 NPC가 잡아 줍니다.
- 삽질·망치·클램프 소리와 약한 카메라 흔들림으로 타격감을 줍니다.

## 지원 플랫폼
- **Windows:** 주 개발 환경입니다.
- **macOS:** 지원 대상입니다. 팀원이 Intel Mac으로 설정과 동작을 확인하는 중입니다. Unity 6의 Intel Mac 지원이 deprecated 상태라 에디터 버전을 고정해 두었고, Apple Silicon은 사용자가 생기면 확인합니다. 철근 결속처럼 마우스 이동량으로 판정하는 조작은 트랙패드와 마우스에서 감도를 따로 확인합니다.

## 만든 방법
- **엔진:** Unity 6 (URP)
- **목표 사양:** 내장 그래픽(Intel Iris Xe)에서 1080p 30fps. 철근 마디는 노멀맵으로 표현하는 등 삼각형 수를 아낍니다.
- **네트워크 / 배포:** Steamworks, 협동은 FishNet 또는 Mirror 검토 중
- **구조:** 규칙 계산(공고 생성, 일당, 피로, 판정)을 Unity와 분리된 순수 C#으로 두고 단위 테스트로 검증합니다. 단계 상태는 서버 권한 구조로 옮기기 쉽게 나눕니다.
- **에셋:** 예산 없이 직접 제작과 무료 라이선스(CC0 등)만 씁니다. 3D 소품은 Blender 스크립트로 만들어 같은 규격으로 관리합니다.
- **협업:** GitHub Issues로 직무와 에셋 작업을 나누고 PR로 리뷰합니다. 이슈 하나가 브랜치와 PR 하나에 대응하고, 프로젝트 보드로 진행을 봅니다.
