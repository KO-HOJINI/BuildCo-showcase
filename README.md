# Build&Co

**인력사무소 일용직에서 시작해, 친구들과 시공사를 세우고 키워 가는 협동 건설 라이프 & 타이쿤**

Steam 출시를 목표로 개발 중입니다. (스토어 페이지 준비 중)

---

## 어떤 게임인가
한국 건설 현장을 배경으로, 현장의 가장 아래에서 시작해 회사를 키우는 게임입니다. 장비 하나를 잡고 의뢰를 수행하는 기존 건설 시뮬레이터와 달리, **인생 역전 커리어**와 **함께 꾸리는 회사**가 중심입니다.

- **손으로 하는 일:** 철근 결속, 보통인부 작업처럼 직종마다 직접 해야 하는 작업이 있습니다. 숙련도가 오르면 더 좋은 일자리가 열립니다.
- **피로와 안전:** 무리하면 사고가 나고, 보호구를 챙기면 안전합니다. 사고는 위험한 행동을 한 결과로만 일어나도록 설계해 억울하지 않게 합니다.
- **협동:** 신호수 없이는 장비를 쓸 수 없는 식으로, 역할을 나눠 맡는 협동 플레이가 기본 설계입니다.
- **분위기:** 현실 고증 7~8, 코미디 2~3의 비율을 지향합니다.

## 성장 경로
일용직으로 시작해 한 단계씩 올라갑니다. 어떤 단계에서 멈춰도 같은 가치로 보상받는 게 목표라, 정해진 엔드게임은 없습니다.

```
일용직 → 전문 기능공 → 반장·소장 → 소규모 시공사 창업
      → 중견 시공사 → 대형 프로젝트 수주 → (선택) 해외 현장 진출
```

| 단계 | 하는 일 |
|---|---|
| 일용직 | 구인 게시판에서 일자리를 골라 현장에 투입, 직접 작업하고 일당을 받음 |
| 기능공 / 장비 기사 | 자격을 따고 숙련도를 쌓아 더 높은 일당의 일을 맡음 |
| 팀장 · 소규모 시공사 | 공종 하나를 위탁받아 인력과 장비를 운영 |
| 종합 시공사 | 수주, 하도급 선정, 현장소장 배치, 회사 조직 운영 |
| 해외 진출 (장기 비전) | 동남아·중동 등 해외 현장. 현지 파트너와 환율·공기 리스크를 다루는 선택형 목표 |

- 실패는 목적이 아니라 운영 리스크입니다. 어려워질 수는 있어도 복구할 길이 항상 있습니다. 해외 사업이 틀어져도 국내 사업으로 돌아올 수 있습니다.
- 소규모 장인 회사, 특화 시공사처럼 키우는 방식이 달라도 같은 가치로 인정합니다.

## 내가 지은 것이 남는 월드
- 도시와 지역은 하나의 월드로 이어지고, 플레이어가 지은 건물·도로·교량은 **영구히 남습니다.**
- 멀리서도 이전에 일했던 현장과 지형지물이 보이는, 마을 이상 규모의 지역을 목표로 합니다.
- 신도시 외곽에서 시작해 농촌, 산업단지, 산악·고속도로 구간으로 단계적으로 열리고, 지역마다 단가와 발주 성향이 다릅니다.
- 건축에서 시작해 도로, 교량, 터널 순으로 공종을 넓힙니다.

## 현재 상태
알파 개발 중입니다. 지금은 아래 흐름이 동작합니다.

- 메인 메뉴, 허브, 구인 게시판, 출근 준비(보호구 착용), 하루 시계
- 철근 결속 작업과 품질 판정
- 피로 게이지, 점심 선택, 위험 행동 경고와 사고
- 하루 끝 정산(일당, 직무 경험치, 품질, 안전)과 자동 저장

한국어를 기본으로 하고 영어를 확장할 계획입니다.

## 만든 방법
- **엔진:** Unity 6 (URP)
- **목표 사양:** 내장 그래픽(Intel Iris Xe)에서 1080p 30fps
- **네트워크 / 배포:** Steamworks, 협동은 FishNet 또는 Mirror 검토 중
- **구조:** 규칙 계산(공고 생성, 일당, 피로, 판정)을 Unity와 분리된 순수 C#으로 두고 단위 테스트로 검증합니다.
- **협업:** GitHub Issues로 직무와 에셋 작업을 나누고 PR로 리뷰합니다.
