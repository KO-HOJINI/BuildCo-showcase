# Build&Co

**건설 현장 일용직에서 시작해 내 회사를 세우는 협동 건설 라이프 게임**

Steam 출시를 목표로 개발 중입니다. (스토어 페이지 준비 중)

---

## 어떤 게임인가
- 일용직 인부로 첫 출근을 하고, 구인 게시판에서 일자리를 골라 하루치 일당을 받습니다.
- 철근 결속, 보통인부 작업 등 직종마다 손으로 직접 하는 작업이 있고, 숙련도가 오르면 더 좋은 일자리가 열립니다.
- 피로와 안전을 관리해야 합니다. 무리하면 사고가 나고, 보호구를 챙기면 안전합니다.
- 장기적으로는 장비 기사, 기능공을 거쳐 회사를 설립하고, 내가 지은 건물이 지역에 남는 것을 목표로 합니다.
- 친구들과 함께하는 협동 플레이를 계획하고 있습니다.

## 현재 상태
알파 개발 중입니다. 지금은 아래 흐름이 동작합니다.

- 메인 메뉴, 허브, 출근 준비(보호구 착용), 하루 시계
- 철근 결속 작업과 품질 판정
- 피로 게이지, 점심 선택, 위험 행동 경고와 사고
- 하루 끝 정산(일당, 직무 경험치, 품질, 안전)과 자동 저장

## 로드맵
| 단계 | 내용 |
|---|---|
| 알파 1a | 싱글 수직 슬라이스: 일용직 루프, 철근 결속, 구인 게시판 |
| 알파 1b | 중장비(굴착기 등)와 신호수 |
| 알파 1c | 협동 플레이(Steam), 골조 층 반복 |
| 베타 | 여러 지역과 이동, 회사 설립, 영속 월드 |

## 만든 방법
- **엔진:** Unity 6 (URP)
- **목표 사양:** 내장 그래픽(Intel Iris Xe)에서 1080p 30fps
- **네트워크 / 배포:** Steamworks, 협동은 FishNet 또는 Mirror 검토 중
- **구조:** 규칙 계산(공고 생성, 일당, 피로, 판정)을 Unity와 분리된 순수 C#으로 두고 단위 테스트로 검증합니다.
- **협업:** GitHub Issues로 직무와 에셋 작업을 나누고 PR로 리뷰합니다.
